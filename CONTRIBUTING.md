# Contributing to Awesome LLM API

Thanks for your interest in contributing! 

## How to Contribute

1. Fork this repository
2. Create a branch: `git checkout -b add-new-model`
3. Make your changes
4. Commit: `git commit -m "Add new model"`
5. Push: `git push origin add-new-model`
6. Open a Pull Request

## What to Contribute

- New LLM models (with pricing and benchmarks)
- New API providers
- Code examples in other languages
- Benchmark updates
- Typo fixes

## Guidelines

- Use the existing table format
- Include pricing in USD per 1M tokens
- Include context window size
- Add a brief "best for" description
- Keep it factual and up-to-date

## Updating Pricing

Pricing changes frequently. When updating:
1. Verify on the provider's official pricing page
2. Update the comparison table
3. Note the update date

Thank you for contributing!
